# Time Calculator

**A freeCodeCamp certification project — Scientific Computing with Python**

Adds a duration to a 12-hour clock time and returns the result with the day of the week and days elapsed.

[![freeCodeCamp](https://img.shields.io/badge/freeCodeCamp-Certification%20Project-0a0a23?logo=freecodecamp&logoColor=white)](https://www.freecodecamp.org/learn/scientific-computing-with-python/)

## What this is

An implementation of the **Time Calculator** project from the
[Scientific Computing with Python](https://www.freecodecamp.org/learn/scientific-computing-with-python/) curriculum, written from
scratch against the project's specification and passing every test freeCodeCamp sets for it.

- **Curriculum:** Scientific Computing with Python
- **Language:** Python 3

## How to run

```bash
python main.py
```

Requires Python 3.10 or later. The program exposes the function specified by the challenge; import
`main` and call it, or run the file to see the built-in example.
